# CareLoop 三板斧 AI 雙引擎戰情室

惠生藥局 × 宇勝生技 × 作惠協會 ‧ vovoball 肌力 × HEALTH Coach 營養陪跑系統（React + TypeScript + Tailwind + Lucide + Vite）

- RBAC 角色視角：👑 三代接班人 / 🩺 L3 藥師／營養師督導 / 🏃 L1/L2 HEALTH Coach；個案一律去識別化 ID（HC-2026-xxx）
- 三本帳嚴格分離：A帳 115 年國健署實績基線（101 位、回訪率 97.0%、825 人次、共識營 47 人）/ C帳 116 年萬海案規劃草案 / B帳 商業授權與門市阿米巴賽馬
- 親愛的長輩雙紅綠燈陪跑卡：M01 需求卡、十食物群 12 週冰箱紀錄、vovoball 出勤精準度、4/8/12 週健康聯絡簿
- AI 臨床紅旗防呆鎖：四大紅旗勾選即鎖定通用建議與商業導購，CareLoop 自動派單至惠生藥局 L3 工作台覆核簽章
- 據點 × 教練三板斧賽馬排行榜 × 🔥 破局含金量，AI 生成給三代接班人的經營／授權建議
- B 端十要素服務包授權報價試算器、去重稽核 CSV、localStorage 持久化

npm install && npm run dev
